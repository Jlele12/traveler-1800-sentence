One sentence, at most 200 characters, explaining the modern internet to a traveler
arriving from the year 1800. Run `python3 main.py` and it writes the sentence to
`/output/entry.txt`:

> A glass window now hangs in every home: through unseen lightning you may speak with
> anyone on Earth, and behind it all mankind's books answer your questions in an instant.

The comparison is true of the internet as it is, and every image in it — glass windows,
lightning, books — is one a person from 1800 already holds.

## Run it

```sh
python3 main.py
```
